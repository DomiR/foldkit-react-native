Add the experimental `foldkit/strict` builder and portable style Schema, plus `toStrictHtml` from `foldkit/strict/web`. A strict view can render through the web adapter or a native builder using the same layout, controls, and event definitions. The strict `textarea` element renders a multiline text field (a `<textarea>` on the web, a multiline `TextInput` on native) whose minimum height follows `Rows`; Return inserts a newline instead of submitting.
